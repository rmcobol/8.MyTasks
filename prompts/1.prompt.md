순수 자바스크립트로 할 일 관리 앱을 만들 거야. 다음 조건으로 기본 프로젝트 구조를 만들어줘.

- index.html, style.css, script.js 3개 파일로 구성
- 빌드 도구나 프레임워크 없이 브라우저에서 바로 실행 가능해야 함
- HTML에 다음 영역의 뼈대만 마크업해줘 (기능 구현은 다음 단계에서 진행):
    1. 상단: 앱 제목 + 진행률 표시 영역
    2. 입력 영역: 할 일 텍스트 입력창 + 카테고리(업무/개인/공부) 선택 드롭다운 + 추가 버튼
    3. 필터 영역: 전체/업무/개인/공부 필터 버튼
    4. 목록 영역: 할 일 리스트가 렌더링될 컨테이너
- 기본적인 레이아웃과 여백만 CSS로 잡아줘 (디테일한 디자인은 이후 단계에서)
- script.js는 빈 파일로 생성하고 index.html에 연결만 해줘
