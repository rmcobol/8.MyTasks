2단계에서 만든 데이터 함수들을 화면과 연결해줘.

- render() 함수를 만들어서 현재 todos 배열을 목록 영역에 그려줘
    - 각 항목: 체크박스, 할 일 제목, 카테고리 태그, 수정 버튼, 삭제 버튼
    - 완료된 항목은 취소선 스타일 적용
- 입력창 + 추가 버튼(또는 Enter 키)으로 addTodo 호출 후 다시 render() 실행
- 체크박스 클릭 시 toggleComplete 호출 후 다시 render() 실행
- 삭제 버튼 클릭 시 deleteTodo 호출 후 다시 render() 실행
- 수정 버튼 클릭 시 해당 항목이 인라인 편집 모드로 전환되고, 제목/카테고리를 수정 후 저장 버튼으로 updateTodo 호출
- 빈 값 입력 시 추가되지 않도록 유효성 검사 추가
- 할 일이 하나도 없을 때는 "할 일이 없습니다" 같은 안내 문구를 표시해줘
- 페이지 최초 로드 시 loadTodos()로 데이터를 불러와 render() 실행해줘
